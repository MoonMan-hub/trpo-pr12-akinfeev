# Практическая работа №12 — Vue 3 Options API

## Результат

Одностраничное приложение «Менеджер задач» на Vue 3 с Options API.
Приложение использует `items.json`, `filters.json` и `ui_states.json` из dataset.

## Требования

- Node.js 18+;
- npm 9+.

## Запуск

```bash
npm install
npm run dev
```

После запуска открыть адрес, который покажет Vite.

## Production build

```bash
npm run build
```

## Структура

```text
src/
├── components/
│   ├── FilterPanel.vue
│   ├── ItemCard.vue
│   └── ItemList.vue
├── data/
│   ├── filters.json
│   ├── items.json
│   └── ui_states.json
├── App.vue
├── main.js
└── style.css
```

## Что реализовано

- Options API: `data`, `computed`, `methods`, `mounted`;
- компоненты `App`, `FilterPanel`, `ItemList`, `ItemCard`;
- передача данных вниз через `props`;
- передача пользовательского действия вверх через `emits`;
- фильтрация и поиск через `computed`;
- состояния `loading`, `error`, `empty`, `success`;
- форма создания задачи с обязательной проверкой названия;
- `v-if`, `v-for` и устойчивый `key` по `id`;
- использование всех трёх файлов dataset;
- адаптивная вёрстка без ручного изменения DOM через `querySelector`.

## Сценарий проверки

1. Запустить проект.
2. Убедиться, что после загрузки отображаются 12 задач.
3. Переключить фильтры «Новые», «В работе», «Готово».
4. Ввести текст в поиск и проверить пересчёт списка.
5. Нажать «Выбрать» у задачи и проверить блок выбранной задачи.
6. Отправить пустую форму и проверить сообщение об ошибке.
7. Создать новую задачу и убедиться, что она появилась в списке.
8. Нажать «Проверить error», убедиться в отображении error state.
9. Нажать «Повторить» и проверить возврат к данным.
10. Выполнить `npm run build` и убедиться, что сборка завершается без ошибок.

## Объяснение архитектуры для защиты

`App` владеет изменяемым состоянием и передаёт данные дочерним компонентам.
`FilterPanel` получает фильтры через `props` и сообщает о выборе через `emits`.
`ItemList` получает массив задач через `props` и передаёт выбор записи дальше.
`ItemCard` отвечает за отображение одной задачи и не изменяет родительский массив напрямую.

`computed.visibleItems` формирует производный список по текущему фильтру и поиску.
`mounted` запускает загрузку данных при инициализации приложения.

## Dataset

- `items.json` — задачи с `id`, `title`, `status`, `priority`;
- `filters.json` — варианты фильтрации;
- `ui_states.json` — состояния интерфейса, включая сообщение ошибки.
